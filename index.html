Aprende, crea y descubre con INFORWEB

Un proyecto pensado para practicar informática, fortalecer nuestros conocimientos y aprender a crear páginas web de una forma sencilla, creativa y divertida.

Explorar proyectos

¿De qué trata el proyecto?

INFORWEB es un proyecto educativo creado para afianzar lo aprendido en Tecnología e Informática. La idea es poner en práctica conocimientos de HTML, CSS y JavaScript mediante la creación de páginas web.

También busca desarrollar la creatividad, mejorar el manejo de herramientas digitales y aprender a organizar la información en internet.

¿Qué podemos aprender?

🧱

HTML

Organizar textos, títulos, imágenes y secciones de una página.

🎨

CSS

Agregar colores, estilos y diseños para mejorar la presentación.

⚡

JavaScript

Crear botones e interacciones sencillas para la página web.
